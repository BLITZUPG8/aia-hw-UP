ภาพรวมรายบริษัท

"ตรงกับงบ" นับจากข้อที่ตรวจได้ (ตรง + ตรงบางส่วน + ไม่ตรง) โดยตรงบางส่วนนับครึ่งข้อ วัดแค่ความถูกต้องของตัวเลข ส่วนเรื่องที่ไม่ได้พูดดูในหัวข้อ "อยู่ในงบแต่ไม่ได้พูด"

ตารางตรวจทุกข้อ

บริษัทนาทีเรื่องผู้บริหารพูดตัวเลขจริงผลหมายเหตุ

ตัวเลขจริงมาจากงบการเงินและ MD&A ที่บริษัทยื่นต่อตลาดหลักทรัพย์ฯ · คำพูดผู้บริหารมาจากคำบรรยายอัตโนมัติของ YouTube ช่อง SET Thailand ซึ่งอาจถอดตัวเลขเพี้ยน จึงยึดตัวเลขจากงบเสมอ · ตรวจด้วยมือ ไม่ใช่คำแนะนำการลงทุน
